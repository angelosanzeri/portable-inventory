# Proteo — brand kit

The Proteo mark is a breaking wave. Proteus was the shape-shifting sea god
who herded and counted Poseidon's seals and knew past, present and future:
an inventory keeper that adapts to any form. The wave is his sea; its lit
barrel gives the mark depth.

## Files

| File | Use |
| :--- | :--- |
| `svg/proteo-icon.svg`, `png/proteo-icon-*.png` | App icon, favicon, avatars (wave on the midnight tile) |
| `svg/proteo-mark.svg` | Mark alone, for dark backgrounds |
| `svg/proteo-mark-light-bg.svg` | Mark alone, for light backgrounds |
| `svg/proteo-mark-white.svg`, `svg/proteo-mark-midnight.svg` | Single-colour mark (print, embossing, overlays) |
| `svg/proteo-logo.svg` / `-white.svg` | Primary horizontal logo, light / dark backgrounds |
| `svg/proteo-logo-descriptor.svg` / `-white.svg` | Horizontal logo with the "L’inventario che lavora come te" descriptor |
| `svg/proteo-logo-stacked.svg` / `-white.svg` | Stacked logo for square spaces |
| `svg/proteo-logo-mono-midnight.svg` / `-mono-white.svg` | Single-colour logo |
| `svg/proteo-wordmark.svg` / `-white.svg` | Wordmark alone |
| `social/proteo-og.png` | Social preview, 1200×630 |

All lettering is converted to outlines, so no font needs to be installed to
use the files.

## Colours

| Name | Hex | Use |
| :--- | :--- | :--- |
| Midnight | `#0b1020` | Icon tile, dark backgrounds, text on light |
| Indigo | `#4f46e5` | Primary brand colour, end of the wave gradient |
| Indigo 400 | `#818cf8` | Middle of the wave gradient |
| Lavender | `#c7d2fe` | Start of the wave gradient, descriptor on dark |
| White | `#ffffff` | Text on dark |

Wave gradient: `#c7d2fe` → `#818cf8` → `#4f46e5`, top-left to bottom-right.

## Typography

[Sora](https://fonts.google.com/specimen/Sora) (SIL Open Font License).
Wordmark: Sora Bold, tracking −3/100. Descriptor: Sora SemiBold, uppercase,
tracking +45/1000.

## Usage

- **Clear space:** keep free space around the logo at least as tall as the
  "o" of the wordmark.
- **Minimum size:** horizontal logo 96 px wide on screen (25 mm in print);
  icon 16 px.
- **Backgrounds:** use the standard files on light backgrounds and the
  `-white` files on dark ones. On photos or busy backgrounds use a
  single-colour version.
- **Don't** recolour the gradient, stretch, rotate or outline the mark,
  change the wordmark's typeface, or rearrange mark and wordmark.

## Source files

The SVGs in `svg/` are the masters: the PNGs, favicons and app icons are
exported from them. When the mark changes, update every variant together so
the set stays consistent.
